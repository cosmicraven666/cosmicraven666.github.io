Hermes V / Privacy

Privacy policy.

Hermes V is a private, self-hosted personal assistant used only by its owner. This policy explains how it handles information received through Google OAuth consent.

Last updated: September 27, 2026

On this page

Google data

With the owner’s consent, Hermes V may access Gmail messages, Calendar events, and Drive files, including Docs and Sheets, within the Google permissions granted. It uses that data to carry out the owner’s requests.

Storage and sharing

OAuth credentials are stored on the owner’s private Hermes system. Hermes may keep Google content or task results on that system for continued personal use; no fixed automatic deletion period is promised. Relevant content may be sent to OpenAI when needed to generate a response to the owner’s request. OpenAI processes that content to provide the response and may retain it under the policies for the OpenAI service used. Google data is not sold or used for advertising.

Access and deletion

The owner can revoke Hermes V’s future Google access in Google Account settings. Revoking access does not delete content already stored locally. As the sole user and operator of the private system, the owner can remove local content and OAuth credentials from that system.

Google data policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website

This is a static information site. Its own code has no sign-in, forms, analytics scripts, or cookies. GitHub Pages hosts the site and may process technical information to deliver it. See the GitHub Privacy Statement for GitHub’s practices.
